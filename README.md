## 1. Antigravity 2.0 Installer & Updater

### Features

- **In-Place Upgrades**: Re-running the script updates Antigravity cleanly to the latest downloaded
  build without losing your session, projects, or settings.
- **Self-Contained User Install**: Installs to `~/.local/share/antigravity` without requiring `sudo`
  or modifying system directories.
- **Terminal Integration**: Installs `antigravity` launcher into `~/.local/bin`.
- **KDE Plasma & Freedesktop `.desktop` Entry**: Creates a standards-compliant desktop file at
  `~/.local/share/applications/antigravity.desktop` with window matching
  (`StartupWMClass=antigravity`), categories (`Development;IDE;`), and mime handlers.
- **Automatic Icon Extraction**: Automatically extracts the official high-resolution **512×512 RGBA
  icon** embedded inside `resources/app.asar`, and generates sized icons (`512x512` down to `16x16`)
  in `~/.local/share/icons/hicolor/`.
- **Custom Icon Support**: Optionally specify your own icon with `--icon /path/to/icon.png`.
- **Automatic Archive Detection**: If no archive path is provided, automatically discovers the
  newest `*Antigravity*.tar.gz` in `~/Downloads` or the current directory.
- **Instant Desktop Refresh**: Updates the KDE Sycoca database (`kbuildsycoca6`), GTK icon cache,
  and desktop database immediately.
- **Clean Uninstallation**: Single-command uninstallation via `--uninstall`.

### Usage

```bash
chmod +x install-antigravity.sh

# Auto-detect latest .tar.gz in ~/Downloads:
./install-antigravity.sh

# Explicit tarball:
./install-antigravity.sh ~/Downloads/Antigravity.tar.gz

# Uninstall:
./install-antigravity.sh --uninstall
```

## 2. Godot Engine Installer & Updater

### Features

- **Safe User-Space Destination**: Installs application files to `~/.local/share/godot-engine`,
  creating a stable symlink `godot` to whichever versioned binary is inside (e.g.
  `Godot_v4.7.2-stable_linux.x86_64`).
  > [!IMPORTANT]
  > Godot natively uses `~/.local/share/godot` for user data (project configs, export templates,
  shader cache) and `~/.config/godot` for editor preferences. By intentionally using
  `~/.local/share/godot-engine` for app binaries, your projects, export templates, and settings are
  **100% safe and untouched during updates or uninstalls**.
- **Automatic `.zip` Discovery**: Automatically detects the newest `*godot*.zip` archive in
  `~/Downloads` or the current directory if no argument is passed.
- **Native Desktop Icon Theme Integration**: Specifies `Icon=godot` in the desktop entry, allowing
  your active desktop icon theme (such as the circular **Tela icon theme**) to dynamically render
  its official styled icon without duplicating files or generating extra PNGs.
- **Custom Icon Support & Fallback**: Optionally install a custom icon via
  `--icon /path/to/icon.png` or fallback cleanly if no icon theme provides a Godot icon.
- **Terminal Integration**: Installs a wrapper script `~/.local/bin/godot` so you can launch Godot
  or run CLI commands (`godot --version`, `godot -e`, headless export, etc.) from anywhere.
- **KDE Plasma `.desktop` Entry**: Creates `~/.local/share/applications/godot.desktop` with
  `StartupWMClass=Godot`, `MimeType=application/x-godot-project;`, and categories
  (`Development;IDE;`), allowing direct file association with `project.godot`.
- **Mono / .NET & Standard Build Support**: Supports standard single-file releases as well as Mono
  (.NET) builds containing the `GodotSharp` folder.
- **Clean Uninstallation**: `--uninstall` cleanly removes the engine binary, desktop file, launcher,
  and icons while preserving your projects and settings.

### Usage

```bash
chmod +x install-godot.sh

# Auto-detect latest Godot .zip in ~/Downloads:
./install-godot.sh

# Explicit zip archive:
./install-godot.sh ~/Downloads/Godot_v4.7.2-stable_linux.x86_64.zip

# Custom icon:
./install-godot.sh --icon ~/Pictures/my-godot-icon.png

# Uninstall:
./install-godot.sh --uninstall
```

### Command-Line Options

```text
Usage:
  install-godot.sh [OPTIONS] [PATH_TO_ZIP]

Options:
  -d, --dest <DIR>       Destination directory for application files
                         (default: ~/.local/share/godot-engine)
  -b, --bin-dir <DIR>    Directory for the terminal launcher command
                         (default: ~/.local/bin)
  -i, --icon <PATH>      Custom application icon (.png or .svg).
                         If omitted, prioritizes the Tela icon theme (if installed)
                         or system/embedded fallback.
  -u, --uninstall        Remove Godot Engine installation, desktop entry,
                         icons, and terminal launcher. User data and settings in
                         ~/.local/share/godot and ~/.config/godot remain intact.
  -h, --help             Show this help message and exit.
```

### Installed File Locations

| Component                | Default Location                            | Notes                                       |
|:-------------------------|:--------------------------------------------|:--------------------------------------------|
| **Engine Binaries**      | `~/.local/share/godot-engine/`              | Stable symlink `godot` + versioned binary   |
| **Terminal Launcher**    | `~/.local/bin/godot`                        | Launch Godot or run CLI arguments           |
| **Desktop Entry**        | `~/.local/share/applications/godot.desktop` | KDE Menu, KRunner & `project.godot` opener  |
| **Application Icon**     | Resolved via `Icon=godot`                   | Uses active theme (Tela) without duplicates |
| **User Projects & Data** | `~/.local/share/godot/`                     | *Untouched by installer/updater*            |
| **Editor Settings**      | `~/.config/godot/`                          | *Untouched by installer/updater*            |

## Launching Applications

- **From KDE Application Launcher / KRunner**: Press `Alt + Space` and search for `Antigravity` or
  `Godot`.
- **From Terminal**:
    - `antigravity`
    - `godot` (or `godot -e` to edit, `godot project.godot` to open a project)
