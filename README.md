## 1. Antigravity App Installer & Updater

### Features

- **In-Place Upgrades**: Re-running the script updates Antigravity cleanly to the latest downloaded
  build without losing your session, projects, or settings.
- **Self-Contained User Install**: Installs to `~/.local/share/antigravity` without requiring `sudo`
  or modifying system directories.
- **Terminal Integration**: Installs `antigravity` launcher into `~/.local/bin`.
- **KDE Plasma & Freedesktop `.desktop` Entry**: Creates a standards-compliant desktop file at
  `~/.local/share/applications/antigravity.desktop` with window matching
  (`StartupWMClass=antigravity`), categories (`Development;IDE;`), and mime handlers.
- **Automatic Icon Extraction**: Automatically extracts the official high-resolution **512×512 RGBA
  icon** embedded inside `resources/app.asar`, and generates sized icons (`512x512` down to `16x16`)
  in `~/.local/share/icons/hicolor/`.
- **Custom Icon Support**: Optionally specify your own icon with `--icon /path/to/icon.png`.
- **Automatic Archive Detection**: If no archive path is provided, automatically discovers the
  newest `*Antigravity*.tar.gz` (excluding IDE tarballs) in `~/Downloads` or the current directory.
- **Instant Desktop Refresh**: Updates the KDE Sycoca database (`kbuildsycoca6`), GTK icon cache,
  and desktop database immediately.
- **Clean Uninstallation**: Single-command uninstallation via `--uninstall`.

### Usage

```bash
chmod +x install-antigravity-app.sh

# Auto-detect latest .tar.gz in ~/Downloads:
./install-antigravity-app.sh

# Explicit tarball:
./install-antigravity-app.sh ~/Downloads/Antigravity.tar.gz

# Uninstall:
./install-antigravity-app.sh --uninstall
```

## 2. Antigravity IDE Installer & Updater

### Features

- **In-Place Upgrades**: Re-running the script cleanly upgrades Antigravity IDE while preserving your
  extensions, workspace settings, and cached state in `~/.antigravity-ide`.
- **Self-Contained User Install**: Installs to `~/.local/share/antigravity-ide` without needing `sudo`.
- **CLI & Remote Integration**: Installs the `antigravity-ide` launcher into `~/.local/bin` along with
  convenient alias `agy-ide`, providing full CLI capabilities (`antigravity-ide .`, `--diff`, etc.).
- **KDE Plasma & Freedesktop `.desktop` Entry**: Creates `~/.local/share/applications/antigravity-ide.desktop`
  with folder/file opening support (`%F`), `new-empty-window` desktop action, and window matching
  (`StartupWMClass=antigravity-ide`).
- **Official Icon Extraction**: Integrates the official 1024×1024 RGBA icon and generates standard
  resolutions (`512x512`, `256x256`, `128x128`, `64x64`, `48x48`, `32x32`, `16x16`) into
  `~/.local/share/icons/hicolor/`.
- **Automatic Archive Detection**: Discovers the newest `*Antigravity*IDE*.tar.gz` in `~/Downloads`
  or current working directory.
- **Clean Uninstallation**: Single-command removal via `--uninstall`.

### Usage

```bash
chmod +x install-antigravity-ide.sh

# Auto-detect latest Antigravity IDE .tar.gz in ~/Downloads:
./install-antigravity-ide.sh

# Explicit tarball:
./install-antigravity-ide.sh ~/Downloads/"Antigravity IDE.tar.gz"

# Uninstall:
./install-antigravity-ide.sh --uninstall
```

## 3. Godot Engine Installer & Updater

### Features

- **Safe User-Space Destination**: Installs application files to `~/.local/share/godot-engine`,
  creating a stable symlink `godot` to whichever versioned binary is inside (e.g.
  `Godot_v4.7.2-stable_linux.x86_64`).
  > [!IMPORTANT]
  > Godot natively uses `~/.local/share/godot` for user data (project configs, export templates,
  shader cache) and `~/.config/godot` for editor preferences. By intentionally using
  `~/.local/share/godot-engine` for app binaries, your projects, export templates, and settings are
  **100% safe and untouched during updates or uninstalls**.
- **Automatic `.zip` Discovery**: Automatically detects the newest `*godot*.zip` archive in
  `~/Downloads` or the current directory if no argument is passed.
- **Native Desktop Icon Theme Integration**: Specifies `Icon=godot` in the desktop entry, allowing
  your active desktop icon theme (such as the circular **Tela icon theme**) to dynamically render
  its official styled icon without duplicating files or generating extra PNGs.
- **Custom Icon Support & Fallback**: Optionally install a custom icon via
  `--icon /path/to/icon.png` or fallback cleanly if no icon theme provides a Godot icon.
- **Terminal Integration**: Installs a wrapper script `~/.local/bin/godot` so you can launch Godot
  or run CLI commands (`godot --version`, `godot -e`, headless export, etc.) from anywhere.
- **KDE Plasma `.desktop` Entry**: Creates `~/.local/share/applications/godot.desktop` with
  `StartupWMClass=Godot`, `MimeType=application/x-godot-project;`, and categories
  (`Development;IDE;`), allowing direct file association with `project.godot`.
- **Mono / .NET & Standard Build Support**: Supports standard single-file releases as well as Mono
  (.NET) builds containing the `GodotSharp` folder.
- **Clean Uninstallation**: `--uninstall` cleanly removes the engine binary, desktop file, launcher,
  and icons while preserving your projects and settings.

### Usage

```bash
chmod +x install-godot.sh

# Auto-detect latest Godot .zip in ~/Downloads:
./install-godot.sh

# Explicit zip archive:
./install-godot.sh ~/Downloads/Godot_v4.7.2-stable_linux.x86_64.zip

# Custom icon:
./install-godot.sh --icon ~/Pictures/my-godot-icon.png

# Uninstall:
./install-godot.sh --uninstall
```

### Command-Line Options

```text
Usage:
  install-godot.sh [OPTIONS] [PATH_TO_ZIP]

Options:
  -d, --dest <DIR>       Destination directory for application files
                         (default: ~/.local/share/godot-engine)
  -b, --bin-dir <DIR>    Directory for the terminal launcher command
                         (default: ~/.local/bin)
  -i, --icon <PATH>      Custom application icon (.png or .svg).
                         If omitted, prioritizes the Tela icon theme (if installed)
                         or system/embedded fallback.
  -u, --uninstall        Remove Godot Engine installation, desktop entry,
                         icons, and terminal launcher. User data and settings in
                         ~/.local/share/godot and ~/.config/godot remain intact.
  -h, --help             Show this help message and exit.
```

### Installed File Locations

| Component                | Default Location                            | Notes                                       |
|:-------------------------|:--------------------------------------------|:--------------------------------------------|
| **Engine Binaries**      | `~/.local/share/godot-engine/`              | Stable symlink `godot` + versioned binary   |
| **Terminal Launcher**    | `~/.local/bin/godot`                        | Launch Godot or run CLI arguments           |
| **Desktop Entry**        | `~/.local/share/applications/godot.desktop` | KDE Menu, KRunner & `project.godot` opener  |
| **Application Icon**     | Resolved via `Icon=godot`                   | Uses active theme (Tela) without duplicates |
| **User Projects & Data** | `~/.local/share/godot/`                     | *Untouched by installer/updater*            |
| **Editor Settings**      | `~/.config/godot/`                          | *Untouched by installer/updater*            |

## 4. LM Studio Installer & Updater

### Features

- **Safe User-Space Destination**: Installs AppImage application files to `~/.local/share/lm-studio`,
  creating stable symlinks (`lm-studio` and `LM-Studio.AppImage`) pointing to the active versioned build.
  > [!IMPORTANT]
  > LM Studio stores downloaded models in `~/.lmstudio` and cache files in `~/.cache/lm-studio`.
  Application binaries in `~/.local/share/lm-studio` are fully isolated, so your downloaded models,
  server configs, and chat histories are **100% safe and untouched during updates or uninstalls**.
- **Automatic `.AppImage` Discovery**: Automatically detects the newest `*lm*studio*.AppImage` in
  `~/Downloads` or the current working directory if no path argument is provided.
- **Disk Space Preservation**: Automatically removes previous multi-gigabyte AppImage builds inside
  `~/.local/share/lm-studio` upon updating to a new version, keeping your SSD clean.
- **Official High-Resolution Icon Extraction**: Automatically extracts the official bundled icons
  across all 8 FreeDesktop resolutions (`16x16`, `24x24`, `32x32`, `48x48`, `64x64`, `128x128`,
  `256x256`, and `512x512`) into `~/.local/share/icons/hicolor/`.
- **Custom Icon Support**: Optionally specify your own icon with `--icon /path/to/icon.png`.
- **Terminal Integration**: Installs `~/.local/bin/lm-studio` plus a convenience symlink
  `~/.local/bin/lmstudio` so you can launch LM Studio from anywhere.
- **KDE Plasma & Freedesktop `.desktop` Entry**: Creates `~/.local/share/applications/lm-studio.desktop`
  with correct window matching (`StartupWMClass=ai.elementlabs.lmstudio`), categories
  (`Development;Science;ArtificialIntelligence;`), and URI protocol handling
  (`MimeType=x-scheme-handler/lmstudio;`).
- **Clean Uninstallation**: Single-command uninstallation via `--uninstall` while preserving your
  downloaded models.

### Usage

```bash
chmod +x install-lm-studio.sh

# Auto-detect latest LM Studio .AppImage in ~/Downloads:
./install-lm-studio.sh

# Explicit AppImage file:
./install-lm-studio.sh ~/Downloads/LM-Studio-0.4.26-4-x64.AppImage

# Custom icon:
./install-lm-studio.sh --icon ~/Pictures/my-icon.png

# Uninstall:
./install-lm-studio.sh --uninstall
```

### Command-Line Options

```text
Usage:
  install-lm-studio.sh [OPTIONS] [PATH_TO_APPIMAGE]

Options:
  -d, --dest <DIR>       Destination directory for application files
                         (default: ~/.local/share/lm-studio)
  -b, --bin-dir <DIR>    Directory for terminal launcher command(s)
                         (default: ~/.local/bin)
  -i, --icon <PATH>      Custom application icon (.png or .svg).
                         If omitted, extracts official icons (16x16 to 512x512).
  -u, --uninstall        Remove LM Studio application files, desktop entry,
                         icons, and terminal launchers. Models in ~/.lmstudio remain intact.
  -h, --help             Show this help message and exit.
```

### Installed File Locations

| Component                | Default Location                                | Notes                                       |
|:-------------------------|:------------------------------------------------|:--------------------------------------------|
| **AppImage Binary**      | `~/.local/share/lm-studio/`                     | Versioned AppImage + stable symlink `lm-studio` |
| **Terminal Launchers**   | `~/.local/bin/lm-studio` & `~/.local/bin/lmstudio` | Launch LM Studio from command line          |
| **Desktop Entry**        | `~/.local/share/applications/lm-studio.desktop` | KDE Menu, KRunner & URL protocol handler    |
| **Application Icons**    | `~/.local/share/icons/hicolor/<size>/apps/`     | Official high-res PNG icons (16x16 to 512x512) |
| **Downloaded Models**    | `~/.lmstudio/`                                  | *Untouched by installer/updater*            |
| **Caches & Settings**    | `~/.cache/lm-studio/`                           | *Untouched by installer/updater*            |

## Launching Applications

- **From KDE Application Launcher / KRunner**: Press `Alt + Space` and search for `Antigravity`,
  `Antigravity IDE`, `Godot`, or `LM Studio`.
- **From Terminal**:
    - `antigravity` (Antigravity Desktop App)
    - `antigravity-ide` or `agy-ide` (Antigravity IDE)

    - `lm-studio` (or `lmstudio`)
