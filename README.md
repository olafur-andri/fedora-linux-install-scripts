# Antigravity 2.0 Installer & In-Place Updater for Fedora Linux (KDE Plasma)

A robust, user-space installer and update utility for **Antigravity 2.0** on Fedora Linux and KDE
Plasma.

> [!NOTE]
> **Attribution**: This utility and documentation were generated by **Antigravity** (Google DeepMind
> Advanced Agentic Coding) using the **Gemini 3.8 Flash** model in pair-programming collaboration
> with the user (October 2026).

## Features

- **In-Place Upgrades**: Re-running the script updates Antigravity cleanly to the latest downloaded
  build without losing your session, projects, or settings.
- **Self-Contained User Install**: Installs to `~/.local/share/antigravity` without requiring `sudo`
  or modifying system directories.
- **Terminal Integration**: Installs `antigravity` into `~/.local/bin` so you can launch it
  directly from any shell or script.
- **KDE Plasma & Freedesktop `.desktop` Entry**: Creates a standards-compliant desktop file at
  `~/.local/share/applications/antigravity.desktop` with proper window matching
  (`StartupWMClass=antigravity`), categories (`Development;IDE;`), and mime handlers.
- **Automatic Icon Extraction**: Automatically extracts the official high-resolution **512×512 RGBA
  icon** embedded inside `resources/app.asar`, and generates sized icons (`512x512`, `256x256`,
  `128x128`, `64x64`, `48x48`, `32x32`) in `~/.local/share/icons/hicolor/`.
- **Custom Icon Support**: Optionally specify your own icon with `--icon /path/to/icon.png`.
- **Automatic Archive Detection**: If no archive path is provided, automatically discovers the
  most recently downloaded `*Antigravity*.tar.gz` in `~/Downloads` or the current directory (sorted
  by modification time).
- **Instant Desktop Refresh**: Updates the KDE Sycoca database (`kbuildsycoca6`), GTK icon cache,
  and desktop database so the application shows up immediately in the Kickoff Application Menu,
  Taskbar, and KRunner (`Alt+Space`).
- **Clean Uninstallation**: Single-command uninstallation via `--uninstall`.

## Quick Start

### 1. Make the script executable

```bash
chmod +x install-antigravity.sh
```

### 2. Initial Installation

Pass the path to your downloaded `.tar.gz` file:

```bash
./install-antigravity.sh ~/Downloads/Antigravity.tar.gz
```

Or run without arguments to auto-detect the newest build in `~/Downloads`:

```bash
./install-antigravity.sh
```

## How to Perform In-Place Upgrades

When a newer version of Antigravity 2.0 is released, updating is quick and straightforward:

### Steps to Update:

1. **Download the new build** from Antigravity's website to your `~/Downloads` folder.
2. **Close Antigravity** if it is currently running (the script checks for running instances to
   prevent file lock issues).
3. **Run the utility script**:

```bash
# Auto-detects the latest downloaded .tar.gz in ~/Downloads:
./install-antigravity.sh

# Or specify the new file explicitly:
./install-antigravity.sh ~/Downloads/Antigravity.tar.gz
```

### What Happens During an In-Place Upgrade:

- **Version Detection**: The script reads the version metadata from `app.asar` before and after
  extraction, displaying the upgrade path (e.g., `v2.19.1 -> v2.20.0`).
- **Clean File Replacement**: The existing application files in `~/.local/share/antigravity/` are
  atomically replaced with the new build.
- **Icon & Desktop Refresh**: Icons and the `.desktop` file are updated, and KDE Plasma's cache
  (`kbuildsycoca6`) is refreshed immediately.
- **User Data Safety**: Your application data, workspace configs, chat history, active tasks,
  credentials, and settings live in `~/.config/Antigravity` (per standard Electron/Linux
  specification) and are **never touched or overwritten during an upgrade**.

## Command-Line Options

```text
Usage:
  install-antigravity.sh [OPTIONS] [PATH_TO_TAR_GZ]

Options:
  -d, --dest <DIR>       Destination directory for application files
                         (default: ~/.local/share/antigravity)
  -b, --bin-dir <DIR>    Directory for the terminal launcher command
                         (default: ~/.local/bin)
  -i, --icon <PATH>      Custom application icon (.png or .svg).
                         If omitted, extracts official 512x512 icon from app.asar
  -u, --uninstall        Remove Antigravity installation, desktop entry,
                         icons, and terminal command.
  -h, --help             Show this help message and exit.
```

## Installed File Locations

| Component               | Default Location                                 |
| :---------------------- | :----------------------------------------------- |
| **App Files**           | `~/.local/share/antigravity/`                    |
| **Terminal Command**    | `~/.local/bin/antigravity`                       |
| **Desktop Entry**       | `~/.local/share/applications/antigravity.desktop`|
| **App Icon (512x512)**  | `~/.local/share/icons/hicolor/512x512/apps/`     |
| **Sized Icon Caches**   | `~/.local/share/icons/hicolor/<size>/apps/`      |
| **User Data & Settings**| `~/.config/Antigravity/` *(Untouched by update)* |

## Launching Antigravity

- **From KDE Application Menu / KRunner**: Press `Alt + Space` and type `Antigravity`.
- **From Terminal**: Run `antigravity` (or in background: `antigravity &`).
